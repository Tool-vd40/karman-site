# Сайт Karman

Лендинг [Karman](https://github.com/Tool-vd40/karman): история буфера обмена, карман для скриншотов и исправление раскладки для Mac.

Живёт на https://tool-vd40.github.io/karman-site/

Вся страница в одном `index.html`, сборки нет. Номер версии и размер `Karman.dmg` подтягиваются из последнего релиза Karman на GitHub.
